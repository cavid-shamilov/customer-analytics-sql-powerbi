# Customer Analytics — SQL Server & Power BI

## Project Overview

This project focuses on Customer Analytics using the Sample Superstore dataset.

The main objective is to analyze customer purchasing behavior, customer value, profitability, retention, and purchasing patterns using SQL Server and Power BI.

The analysis aims to identify the most valuable customers, understand what drives customer value, and discover opportunities to improve customer retention and profitability.

## Dataset Source

- **Dataset:** Sample Superstore
- **Source:** [Kaggle — Sample Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
- **Records:** Approximately 9,994 rows
- **Columns:** 21

## Data Grain

One row represents an individual product line within an order.

Each record contains information about a product sold as part of a customer order.

## Column Descriptions

| Column | Description |
|---|---|
| Row ID | Unique identifier assigned to each row in the dataset. |
| Order ID | Identifier of the customer's order. |
| Order Date | Date when the order was placed. |
| Ship Date | Date when the order was shipped. |
| Ship Mode | Shipping method selected for the order. |
| Customer ID | Unique identifier assigned to each customer. |
| Customer Name | Name of the customer. |
| Segment | Customer segment: Consumer, Corporate, or Home Office. |
| Country | Country where the order was placed. |
| City | City associated with the order. |
| State | State associated with the order. |
| Postal Code | Postal code associated with the order location. |
| Region | Geographic region associated with the order. |
| Product ID | Identifier of the product. |
| Category | Main product category. |
| Sub-Category | More specific product classification. |
| Product Name | Name of the product. |
| Sales | Sales amount for the product line, after discounts. |
| Quantity | Number of units sold in the product line. |
| Discount | Discount rate applied to the product line. |
| Profit | Profit or loss generated by the product line. |

## Initial Understanding of Key Metrics

- **Sales:** Represents the sales amount for a product line after the applied discount.
- **Quantity:** Indicates the number of units purchased.
- **Discount:** Represents the discount rate applied to a product line (e.g., 0.45 = 45%).
- **Profit:** Represents the profit or loss associated with a product line. A negative value indicates a loss.
